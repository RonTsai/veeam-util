# veeam-util

Utilities for Veeam Backup & Replication.

**Author:** Ron Tsai @Veeam Taiwan

| Tool | Description |
|---|---|
| [vbr-topology](vbr-topology/) | Scans a VBR server and draws its backup architecture as an interactive HTML report: data movers, job data flow, Enterprise Manager, and the ESXi host each component runs on. PowerShell and Python versions. Read-only. |
